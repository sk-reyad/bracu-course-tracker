https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum

Verify and explain:

- Minimum pointer target size of 24 × 24 CSS pixels
- The spacing exception using 24 CSS pixel diameter circles
- Equivalent control exception
- Inline exception
- User-agent-control exception
- Essential exception
- Rounded-corner and usable target geometry considerations
- Difference between target dimensions and the visual appearance of the control

## 5. Target Geometry Audit

Inspect actual rendered interactive targets, not just declared CSS rules.

For each version, collect:

1. Target element and semantic role.
2. Actual rendered bounding rectangle.
3. Width and height in CSS pixels.
4. Clickable hit-test results within the relevant visible surface.
5. Border, padding and rounded-corner behavior.
6. Whether the target itself contains a usable 24 × 24 CSS px square.
7. Whether it satisfies the minimum target-size requirement directly.
8. If undersized, whether a documented exception applies.
9. Adjacent target identity and proximity.
10. Any clipping, transformed bounds or overlapping pointer targets.

Include the actual stream badge trigger and nearby actionable controls.

Examine the disclosure's "See more" button when visible, along with relevant neighboring course-card controls.

Do not count noninteractive labels as pointer targets.

Distinguish closed and opened disclosure states.

Document excluded elements and why they were excluded.

## 6. Spacing Exception Verification

For undersized targets, perform the spacing assessment described by SC 2.5.8.

Construct the 24 CSS pixel diameter circles centered on the target bounding boxes.

Check whether those circles intersect:

- Other actual targets
- Other 24px circles for undersized targets

Correctly distinguish the target rectangle from its hypothetical spacing circle.

Include nearby buttons and links when relevant.

Test arrangements where multiple stream badges or other controls appear close together.

If two targets are sufficiently separated, document the actual clearance.

If spacing fails, document the specific neighboring target and intersection.

Do not simply assume that an undersized target fails.

Do not confuse a generic center-to-center distance check with the normative spacing rule.

When CSS shapes or overlapping elements make the outcome ambiguous, identify the limitation and use additional hit-testing evidence.
