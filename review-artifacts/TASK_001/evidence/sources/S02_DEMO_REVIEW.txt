## Isolation

serve.cjs applies identical isolation to both copies: it serves a synthetic
browser config in memory, blocks nonlocal connections with CSP, rejects writes,
and disables Auth/Admin routes. No production config file was edited. CDN font,
icon and SDK scripts can load; production database/Auth/Storage/function calls
cannot connect. Guest support opens locally, but security challenge/submission
is intentionally unavailable. Do not use this server for production.

Only tracked source from git archive was exported; no .git history, private
.env, browser sessions, database backups or untracked user work was copied.
Student records are the supported synthetic read-only preview. Bundled public
faculty reference records retain their original content. Clipboard tests use
demo-faculty@example.invalid and a mocked clipboard boundary.

## Demo A — accessibility foundation

Modal focus enters the close control, cycles within the top modal, restores to
the opener, and keeps background siblings inert. Existing inert states/body
scroll styles are restored. Native nested support dialog keeps its own Escape
behavior. Existing tracker overlay structure and mobile scrolling are retained.
Four close buttons have specific names. Settings tabs expose roles, ownership,
selection, roving tabindex, panel visibility and Arrow/Home/End navigation.
Appearance changes only when keyboard focus is visible.

## Demo B — stream disclosures

Closed panels use display:none. Open details are temporarily moved outside
card/scroller transforms to body, clamped to client width and viewport height,
and restored on dismissal. Long content wraps and can scroll. Resize/page
scroll dismisses the panel; click, Escape, outside click and keyboard traversal
to See more work. Triggers are at least 24px high; text style remains unchanged.
Existing --shadow replaces the undefined --shadow-lg.

No document overflow hiding was added. In both themes, the six tested CSS
widths produced these root client/scroll pairs:

| Viewport | clientWidth | scrollWidth |
| --- | ---: | ---: |
| 360 | 345 | 345 |
| 390 | 375 | 375 |
| 768 | 753 | 753 |
| 1024 | 1009 | 1009 |
| 1280 | 1265 | 1265 |
| 1440 | 1425 | 1425 |

geometry.json contains all 24 width/theme/edge measurements, tooltip bounds,
trigger dimensions, and computed shadow. The scrollbar explains the 15px
difference from viewport width. The prerequisite map retains its own scroller.

## Demo C — reduced motion

Back to Top, stream See more and Admin Catalog editor choose instant scrolling
under reduce and retain smooth under no-preference. Copy success retains its
icon/check, live message, accessible label and reset; only the pop movement is
suppressed under reduce. Admin Catalog's selection is verified with a synthetic
DOM harness, not an authenticated browser session.
