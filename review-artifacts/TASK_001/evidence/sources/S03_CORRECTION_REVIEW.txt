## Task 2 — PASSED

The interactive stream panel now has role=group and an escaped accessible name
matching its visible curriculum title. This is a button-controlled non-modal
disclosure, not a dialog: opening retains focus on the trigger, Tab visits
See more, and no modal focus model is introduced. The existing aria-expanded
and aria-controls relationship remains in place.

This follows the [WAI disclosure pattern](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/);
the [WAI tooltip pattern](https://www.w3.org/WAI/ARIA/apg/patterns/tooltip/)
does not fit a panel with a focusable action. Only the role and accessible name
were changed. No positioning, CSS, scrolling, card or connector code changed
for this correction.

verify-stream-semantics.mjs passed in both themes:

- Enter and Space open; trigger expanded state and controls target are correct.
- Tab reaches See more; Shift+Tab returns to the trigger.
- Escape from the action closes the panel and returns focus.
- Pointer toggle and outside-click dismissal still work.
- Keyboard See more activation closes the panel and focuses the Course List filter.
- Chrome's accessibility tree exposes the named group and the See more button.

See [AX/keyboard evidence](after-evidence/stream-semantics.json).
The light and dark popup bounds are identical before/after; see
[preservation evidence](after-evidence/preservation.json).
