## 4. Implementation Requirements

Inspect the current structure, where a stream badge contains a disclosure trigger and a tooltip with a separate "See more" button.

Implement the alternative using valid, accessible HTML.

Do not create:

- Nested interactive buttons
- A clickable span without appropriate keyboard semantics
- Duplicate keyboard focus targets
- Conflicting parent/child click handlers
- Invalid interactive nesting
- Multiple disclosure activations from a single pointer event

Ensure:

1. The intended full visible badge surface is clickable.
2. The actual hit area is measured, not inferred from appearance.
3. Keyboard users can activate the disclosure through Enter and Space.
4. A visible focus indicator remains.
5. aria-expanded accurately reflects disclosure state.
6. Opening one stream tooltip and closing another works correctly.
7. Escape and outside-click dismissal remain correct.
8. The "See more" button remains independently accessible and functional.
9. Its Course List navigation/filter behavior remains unchanged.
10. No clipping, accidental stacking, or horizontal page overflow is introduced.
11. Hover, focus and click interaction remain consistent.
12. Badge colors, typography and academic status styles remain unchanged.
13. The existing selected Demo B tooltip improvements remain intact.

Pay special attention to the relationship between the badge's interactive surface and the tooltip's separately interactive controls.

Prefer a small, semantically correct implementation over complex event-handler workarounds.
